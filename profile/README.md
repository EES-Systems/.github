# EES Systems Engineering & Integration

### Engineering intelligent, reliable and connected industrial systems

EES Systems Engineering & Integration develops practical engineering
resources, configuration examples, selection tools and open-source
utilities for industrial automation, electrical systems, instrumentation,
industrial communications, OT/IT integration and digitalization.

Our objective is to share useful, validated and reusable engineering
knowledge that helps engineers design, select, configure, test and
commission industrial systems more effectively.

---

## What We Cover

### Automation and Control

- PLC, PAC, RTU and DCS architectures
- SCADA and HMI systems
- Redundant and high-availability control systems
- Process, machine and infrastructure automation
- Control philosophy and functional design
- FAT, SAT and commissioning practices

### Electrical Engineering

- Control and automation panels
- MCC, VFD and soft-starter applications
- 24 VDC control-power sizing
- UPS and backup-power sizing
- Cable, breaker and busbar calculations
- Control-panel thermal calculations
- Electrical design and verification tools

### Instrumentation

- Field-instrument selection
- 4–20 mA signal calculations
- Instrument-range and unit conversion
- I/O and loop engineering
- Instrument index and data-sheet templates
- Loop-checking and commissioning resources

### Industrial Communications

- PROFINET and PROFIBUS
- Modbus RTU and Modbus TCP
- OPC UA
- EtherNet/IP
- MQTT and industrial IoT connectivity
- DNP3, BACnet and IEC 61850
- Industrial Ethernet and protocol integration

### Systems Integration

- Multi-vendor architecture development
- PLC, DCS, SCADA and RTU integration
- Legacy-system modernization
- OT/IT and ERP integration
- Edge-to-cloud connectivity
- Data acquisition, dashboards and reporting
- Industrial cybersecurity engineering

### Industrial Digitalization and AI

- Industrial IoT applications
- Edge computing
- Operational-data collection
- Equipment and energy analytics
- Condition monitoring
- Engineering knowledge systems
- AI-assisted engineering workflows

## Engineering Principles

Every EES public engineering resource should clearly identify:

1. Purpose and intended use
2. Required inputs
3. Calculation or selection method
4. Assumptions
5. Applicable standards and references
6. Known limitations
7. Validation status
8. Software and hardware versions
9. Worked examples
10. Revision history

Safety-critical and project-specific engineering decisions must always
be reviewed and approved by qualified professionals.

## Contributing

We welcome technically sound contributions from automation, electrical,
instrumentation, software and systems-integration professionals.

You can contribute by:

- Reporting an error
- Improving technical documentation
- Adding a worked example
- Proposing a new engineering tool
- Improving tests or validation
- Adding a supported protocol or platform
- Submitting a pull request

Before contributing, please read the repository's:

- `CONTRIBUTING.md`
- `SECURITY.md`
- `CODE_OF_CONDUCT.md`
- `LICENSE`
- Technical validation requirements

Please do not submit customer information, credentials, proprietary
project files, confidential information or copyrighted manufacturer
material.

## Security and Confidentiality

Do not publish:

- Passwords, tokens or API keys
- PLC, SCADA or server credentials
- Customer IP addresses or network diagrams
- Private certificates or SSH keys
- Software license keys
- Customer programs or project backups
- Commercial proposals or costing information
- Personally identifiable or confidential information

Potential security issues should be reported privately using the
instructions in `SECURITY.md`.
